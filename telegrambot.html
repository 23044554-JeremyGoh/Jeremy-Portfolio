App Overview

MontfortCareNearbyBot is a Telegram chatbot prototype developed to help users conveniently locate nearby Montfort Care centres, services, and community activities through Telegram. The bot allows users to browse service categories, search by postal code or location, and explore activities available at different centres using a simple and user-friendly interface.

Features Of The Bot

  • Allows users to browse centres by categories such as Families, Children, Seniors, Mental Health, Caregiving, and Anti-Violence.
  • Supports postal code and location-based search to recommend nearby services and centres.
  • Displays centre information including address, contact number, email, and estimated distance from the user.
  • Allows users to view activities available at each centre, including schedules, timings, recommended audience, and sign-up instructions.
  • Supports keyword-based activity search for programmes such as workout sessions, tai chi, and parenting activities.
  • Uses interactive Telegram inline buttons to create a more user-friendly and accessible experience.

Challenges

  • Designing a chatbot flow that allows users to navigate services easily without confusion.
  • Integrating location and postal code search functionality using external APIs.
  • Organising centre and activity data dynamically for clear and readable presentation.
  • Handling different types of user input such as category selection, postal code entry, and keyword searches.
  • Creating a practical and accessible solution suitable for real-world users through a messaging platform.
